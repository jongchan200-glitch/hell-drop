# 지옥 낙하 캐릭터 검수본

우이지·우서이 원본 일러스트와 우이지의 36프레임 낙하 아틀라스를 참고해 새 A 자세 원화를 만들었다. 두 캐릭터는 한 스켈레톤과 네 동작을 공유한다. V2–V4 원화와 렌더러는 이 제작본에 포함되지 않는다.

## 열기

- **review.html**을 다운로드해 브라우저에서 열면 오프라인으로 시연할 수 있다. 캐릭터, 낙하/벽점프, 헬멧/밀폐 탈, 의상, 장갑, 신발, 팔찌, 망토와 게임 크기를 선택하고 느린 재생 또는 타임라인을 사용한다.
- **hell-drop.rigby**는 35개 이미지를 포함한 편집 원본이다. [Rigby2D 브라우저 편집기](https://rigby2d.com/editor/)에서 파일 → 열기로 연다.
- **hell-drop.json**, **hell-drop.atlas**, **hell-drop.png**는 같은 폴더에 두는 스켈레톤 4.2 내보내기 세트다. 상의·바지, 머리, 헤어, 망토, 장갑, 팔찌, 신발은 슬롯 또는 스킨으로 관리한다.
- **neutral-art.png**는 두 캐릭터의 제작용 A 자세 원화다. **build-rig.py**는 Pillow로 메시·아틀라스를 만들며 **review-template.html**은 시연의 편집 소스다. 네이티브 파일을 재생성하려면 Rigby2D에서 내보내기 세트를 가져와 작업 파일로 저장할 수 있다.

## 현재 검수 상태

Rigby2D 0.6.0 브라우저 편집기에서 JSON과 아틀라스 가져오기, 네이티브 파일 재열기, 38개 본, 15개 슬롯, 6개 스킨, 네 애니메이션을 확인했다. 별도 Chromium 시연으로 우이지 일반 낙하와 양쪽 벽점프, 우서이 헬멧 고속 낙하, 의상·장갑·신발 교체, 밀폐 탈, 게임 크기 표시를 눈으로 확인했다. 벽점프의 기울기 방향과 발차기 방향은 좌우 대칭으로 보정했다.

시제품의 관절 범위는 네 애니메이션 키프레임을 제한해 유지한다. 편집기에서 자유롭게 포즈를 잡을 때 작동하는 강제 각도 제한이나 벽 접촉 발 고정 IK는 적용되지 않았다. 정면 원화를 이용한 2D 포즈라 원본 아틀라스의 발바닥 원근과 고속 표정은 재현되지 않았다. 팔꿈치의 실루엣, 헬멧과 망토의 원화 마감, 우서이 뒷머리의 길이·흔들림과 장비 겹침은 추가 검수 대상이다. 실제 게임 맵·갤럭시·Android Studio 빌드에서는 시험하지 않았다.

이 브랜치는 사용자 검수용이다. 게임 본편, 코인, 저장 기록, 상점 데이터는 연결되어 있지 않다.
