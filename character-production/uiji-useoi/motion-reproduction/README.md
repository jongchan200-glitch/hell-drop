# 원본 동작 비교 검수 · 2026-11-25

**compare.html**을 내려받아 브라우저에서 연다. 왼쪽은 원본 캐릭터 렌더링 함수와 원본 이미지, 오른쪽은 가중 메시 관절형 캐릭터다. 두 화면은 같은 시각·속도·벽 사이 좌표로 재생한다. 이전/다음 버튼이나 슬라이더로 탐색하고, **프레임 표 만들기**를 누르면 벽점프를 0–400 ms의 25개 표본으로 나란히 볼 수 있다. 게임 크기 표시는 양쪽에 같이 적용된다.

## 본편에서 확인한 동작

- 우이지 아틀라스는 384×384 셀 36개다. 0–11은 망토 펼침, 12–23은 접힘, 24–35는 고속이다. 원본 화면은 게임과 같은 프레임 선택·박자·스케일을 사용한다. 관절형 몸체는 각 모드의 원화 실루엣을 참고했고, 셀의 픽셀 경계 변화는 팔다리·몸체의 소폭 변화에 반영했다.
- 우서이 낙하에 본편이 호출하는 이미지는 `hero_cape.webp`다. `hero_fall.webp`도 열어 비교했으나 이 모드에서 `drawHero`가 교체하는 프레임은 아니다. 접힘은 같은 그림에서 망토 양쪽의 회전·수축으로 생긴다.
- 우서이 벽점프는 방향별 킥 원화 한 장을 기울이고 키운 뒤, 260–400 ms에 펼친 망토 자세와 섞는다. 벽 사이 좌표 이동은 약 155 ms, 캐릭터 자세 구간은 약 400 ms다. 우이지는 좌우 벽점프에도 현재 낙하 아틀라스 자세에 방향 반전·기울기를 적용한다.

## 관절형 보정과 남은 차이

이전 720 ms 벽점프를 400 ms로 맞췄다. 양쪽 출발 발의 높이와 앞팔 방향, 우서이 뒷머리 방향, 착지 시 망토 복귀를 조정했다. 우서이 고속 낙하에서는 접힌 망토와 함께 팔이 몸 가까이 모이고, 장갑과 신발은 손·발의 하위에 유지된다. 브라우저에서 우서이 양방향 25프레임 표와 보정 뒤 헬멧·교체 신발을 확인했다.

우서이 원본 킥의 측면 얼굴·주먹·발바닥 원근과 풍성하게 휘날리는 머리카락은 정면 원화로 만든 현재 리그에 여전히 차이가 있다. 킥 발은 벽 방향으로 올라가지만 벽에 고정하는 IK 접점은 구현되지 않았다. 우이지 36개 원본 셀의 관절 위치를 각각 수작업으로 추적한 결과도 아니다. 실제 갤럭시 확인과 사용자 승인 전 검수본이다.

`hell-drop.rigby`는 편집 원본이다. `hell-drop.json`, `hell-drop.atlas`, `hell-drop.png`는 함께 사용하는 데이터다. 원본 비교에 사용한 게임 기준 커밋은 `0f4505a`이며, 2026-11-25에 확인한 main `67c8913`에서도 원본 캐릭터 렌더링과 이동 공식이 일치했다. 본편은 수정하지 않았다.
