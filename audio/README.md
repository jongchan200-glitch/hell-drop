# 지층별 BGM 교체 슬롯

리듬게임에서 직접 제작한 편곡 음악의 사용 허가 및 파일을 확보한 뒤 연결합니다.

- menu.ogg — 홈 화면
- zone_01.ogg — 지표면·지하 동굴
- zone_02.ogg — 깊은 암반층
- zone_03.ogg — 마그마 지대
- zone_04.ogg — 맨틀 지대
- zone_05.ogg — 외핵
- zone_06.ogg — 내핵
- zone_07.ogg — 지옥의 심연

음원을 넣은 뒤 `systems.js`의 `MUSIC_SLOTS[].ready` 값을 true로 변경하면 해당 구역에서 반복 재생합니다. 지층 전환 때 2.2초 교차 페이드. 사용자 설정에 BGM/SFX 별도 음량 저장. 실제 파일이 없으면 음악은 재생되지 않음. 원곡의 저작권 및 편곡/음원 권리를 별도로 확인해야 합니다.
