# 지옥 낙하 WEB V0.7 — 전면 리디자인 홈 로비 + 5회 연타 (2026-11-23)

고정 게임 주소: https://jongchan200-glitch.github.io/hell-drop/

## 실제 반영 사항

- **새 메인 로비**: 독자적으로 생성한 `assets/lobby_abyss.webp` 지하 성전/용암 배경, 조명·빛 입자·미세 배경 움직임, 오리지널 우서이 전신 캐릭터, 골드/다크 판타지 색채, 상단 레벨/코인, 간결한 최고 기록/누적 깊이, 큰 시작 버튼, 5개 메뉴 캐릭터/상점/코인/기록/설정. 기존 카드형 테스트 홈 폐기.
- **캐릭터 인터랙션**: 기존 원본 `assets/hero_intro.webp`를 그대로 사용. 대기 중 호흡·좌우 무게중심 이동과 망토 흔들림 느낌을 주는 60fps CSS idle, 손가락 좌우 드래그/키보드 좌우키로 2D 일러스트를 최대 ±55도 원근 회전. 해당 회전은 **2D 시안**이며 원본 한 장으로 실제 뒷모습을 표현하거나 완전한 360도 3D 회전을 보장하지 않는다. 추후 캐릭터마다 옆/뒷모습 원화가 생기면 대체할 수 있도록 분리. 외형/얼굴 자체는 재생성하지 않았다.
- **시작 오프닝 제거**: 버튼을 누르면 오래된 구멍 뛰어드는 2.45초 연출 없이 바로 `PLAYING`에 진입한다. 홈의 idle과 실제 게임 애니메이션은 별개.
- **가속 기준 변경**: 기존 초당 3회(VER 0.6)에서 **초당 약 5회** 유지 시 최고 게이지로 변경. `TAP_RATE_BASE=0.8, TAP_RATE_RANGE=4.0, FALL_RESPONSE=6.7`, 대기 유예도 실제 빠른 연타에 맞춤. 감속은 V0.6보다 빠르게. 최고 낙하속도 수치는 유지.
- **왼쪽/오른쪽 조작**: V0.6의 기존 사용자 선택 및 `hell_fall_profile_v1` localStorage 유지. 캐릭터·상점·코인·기록·설정 패널 기능 유지. 캐릭터 패널에는 현재 한 명의 실제 선택 상태와 향후 슬롯을 설명.
- **기록 안전**: `hell_fall_web_v42_best` 최고 기록 / `hell_fall_profile_v1` 코인·레벨·누적·BGM/SFX·버튼 위치를 삭제/마이그레이션하지 않음. 외부 광고/현금결제는 미연결.
- **8분 시뮬레이터 유지**: `simulator.html` 및 관련 파일은 수정하지 않음. 실제 8분 클리어 난이도, 지층 확장, 코인 빈도·시계 밸런스는 별도 후속 작업이므로 현 V0.7 실제 플레이에는 반영되지 않음.

## UX 테스트 포인트

갤럭시 세로 화면에서 시작 즉시 PLAYING 진입; 좌우 드래그가 메뉴 탭과 충돌하지 않는지; 캐릭터를 누르면 정면 복귀/회전; 상점/설정 팝업 접근; 설정에서 가속 버튼 위치가 그대로 유지되는지; 약 초당 5회 연타하여 최고 가속과 빠른 감속을 체감하는지 확인.

## 아트 소유/재사용

배경은 해당 프로젝트용으로 신규 생성한 비문자 이미지이며 압축된 `lobby_abyss.webp`로 저장. 타 게임 UI 이미지는 구현물에 복제하거나 탑재하지 않았음. `hero_intro.webp`는 이전 V4.2 원본. 아이템 착용 표시와 본격 3D 회전은 차후 실제 장비/다각도 스프라이트 자산 마련 전에는 예고된 기능이 아닌 준비된 확장 방향이다.
